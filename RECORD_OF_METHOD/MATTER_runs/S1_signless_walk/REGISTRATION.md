# S1 — a signless (Majorana-type) spin-½ pattern: is its backward branch independent, and does a commuting (bosonic) version move at all?

**Question.** The first rung says positivity of the count forces exclusion for a pattern with an independent backward branch, which a sign gives. A signless spin-½ pattern must still be a fermion in nature. Does CO force it, and by what?

**Construction.** The adopted walk U(k) (palindrome, alternation mass) is charge-conjugation symmetric: C U(k)* C⁻¹ = U(−k) for the Dirac-representation C. A signless pattern is one with ψ = C ψ*. Its one-step bilinear is ψᵀ C G ψ with G(k) = i log U(k) the generator. For commuting (bosonic) components a bilinear ψᵀ A ψ sees only the symmetric part of A; for anticommuting (fermionic) components only the antisymmetric part.

**Measured quantity.** The symmetric part S(k) = ½[C G(k) + (C G(−k))ᵀ] and the antisymmetric part A(k) over the zone. If S ≡ 0 and A ≠ 0: a commuting signless pattern has no generator, i.e. does not move; only the anticommuting version is a pattern at all. If S ≠ 0: a bosonic signless spin-½ pattern can move, and CO does not force its statistics.

**Outcome unknown before the run.** Changes a ruling either way.
