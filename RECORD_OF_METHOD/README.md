The working records: every route tried, every withdrawal with its reason, the runs with their result notes. The clean documents at the root report what stands; this folder reports how it got there and what did not survive.

- [`SPACE_AND_GRAVITY_record.md`](SPACE_AND_GRAVITY_record.md), with runs R1–R7b in [`SPACE_AND_GRAVITY_runs/`](SPACE_AND_GRAVITY_runs/)

- [`NUCLEUS_record.md`](NUCLEUS_record.md)

The method: a rule is added only where the primitives are silent and only if it retires something; a rule may also be added on a named contradiction with the world; a rule whose prerequisites are not ruled stays candidate; nothing is deleted, only struck through with its reason.
