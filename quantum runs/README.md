# Quantum runs

This folder holds the write-up sections of the quantum-sector runs: tests of when a pattern of possibility commits, and of what a commitment records.

No quantum-sector run has been made yet. The design note that sets out the requirements, the candidate rules and the tests I1–I4 is Note I, [`../runs/design_commitment_quantum.md`](../runs/design_commitment_quantum.md). Its standing ruling (26 October) is that a commitment is stamped with the local count (ONTOLOGY §1).
