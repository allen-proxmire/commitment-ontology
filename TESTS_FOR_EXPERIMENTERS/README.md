# Tests for experimenters

One-page notes, each stating a measurement that would test the Commitment Ontology (CO), what CO predicts, what standard physics predicts, and which existing setups could do it. They are open notes: none has been sent to, or seen by, the groups or collaborations named, and naming a group means only that its published setup fits the measurement.

| note | measurement | platforms named |
|---|---|---|
| [`photon_ceiling.md`](photon_ceiling.md) | a direction-dependent ceiling on cosmic photon energies, the same for near and far sources | LHAASO, Tibet ASγ, HAWC, SWGO, Pierre Auger Observatory, Telescope Array |
| [`neutrino_flavour.md`](neutrino_flavour.md) | extra muon-neutrino disappearance through the Earth, growing with energy, aligned with the standard mixing | IceCube (and IceCube-Gen2), KM3NeT/ARCA and ORCA, Baikal-GVD, Super-Kamiokande and Hyper-Kamiokande |
| [`stopping_number_echo.md`](stopping_number_echo.md) | whether the breadth of an irreversible many-body echo stops growing at a universal number N | solid-state NMR in adamantane (the Pastawski–Sánchez setup; spin counting as in Cappellaro's group), Rydberg arrays with dipolar exchange (Geier et al.), superconducting-qubit lattices (Braumüller et al.) |

Each note's figures follow the results docs ([`README.md`](../README.md), [`OPEN_DIRECTIONS_notes/prediction_map.md`](../OPEN_DIRECTIONS_notes/prediction_map.md)); where they differ, the results docs are current.
